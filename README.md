# Git
This repository contains my notes and practical exercises from the Git section of my DevOps course.
The aim is to build a solid understanding of Git, from the fundamentals of version control through to branching, collaboration, GitHub workflows, and security.

# Topics Covered
Git fundamentals & repository structure
Basic Git workflow & essential commands
Git history & differences
Git configuration & SSH
Remote repositories & GitHub
Branching, merging & conflict resolution
Rebase, stash & cherry-pick
Undoing changes & amending commits
GitHub collaboration workflows
.gitignore & pre-commit hooks
Git security & secret management

# Repository Structure
notes/       → Detailed course notes and Git references
examples/    → Practical Git exercises and examples

# Learning Goal

Use Git confidently for version control and understand how it fits into a modern DevOps workflow.
